# muse-custom-skills

Custom skills I built for my AI assistant (Muse), collected in one place.

## Skills

### arduino_breadboard_prototyping
A step-by-step playbook for building breadboard Arduino prototypes from an
inventoried parts list and one verified power source, all the way to a tested
circuit. Written for an Arduino Uno clone + 16x2 LCD with a PCF8574 I2C
backpack, but the method is general.

### scheduled_course_item_verification
Verify each scheduled course item (quiz, test, lab, class) against its
authoritative page before reporting its time or status — never trust a stale
course-page listing or a remembered time.

### canva-browser-mastery
Design in the Canva web editor by hand, without any Canva AI generation:
templates, text, layers, brand, video, export and browser driving notes.
Learned from building the BLACK BOX test card through six critique loops.

### scheduled_job_decision_propagation
When a method, channel, or approach is stopped or retired in chat, propagate
the decision into the scheduled jobs and runbooks that still carry it out —
pause or rewrite the job definition, not just the next reply — so no stale
job keeps running the old routine.
