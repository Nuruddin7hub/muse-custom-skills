# Verify Each Scheduled Course Item Before You Report It

## Check one item at a time

- Open the authoritative page for the single item you are checking, such as the quiz page, the activity page, or the timetable entry for that item.

- Read the time, date, venue, group, and status from that page before you write anything about the item.

- Treat a course outline, a planner, a summary list, or an earlier message as a pointer to the item, not as proof of its current time or status.

- Check the group label on the page against the user's group before you name a time or act on the item.

- When two sources disagree, report the authoritative page value and name the other source as conflicting, and do not blend the two values into one time.

## Keep distinct activities separate

- Keep attendance, homework, quizzes, tests, and labs as separate items even when they share a course or a topic.

- Do not infer that completing one activity completes another, and do not infer that missing one means missing another.

- Check attendance from the attendance record, homework from the homework record, and each assessment from its own page.

- When evidence covers only one activity, report only that activity and say the other activity is still unchecked.

## Draft messages only from explicit evidence

- Draft a message about a missed session, a late submission, or a failed requirement only when the authoritative record shows that exact outcome for that exact item.

- Do not draft such a message from a merged record, a guessed time, or an unchecked activity.

- When the record is unclear, ask the user or report the item as unverified, and keep the draft out of the report.

- Never start an attempt or submit work while checking, unless the user explicitly told you to do so for that item.

## Present what you verified

- Give the item name, the verified time or status, the group when it applies, and the source page you read for that item.

- Mark any item you could not open as unverified, and say what is still needed to verify it.

- Lead with the caveat when a time is group specific, so the user sees whether it is theirs before acting on it.

## Alternatives for better results

- Ask the user to confirm the group or the item when the authoritative page does not name it clearly.

- Re-read the authoritative page after any correction, instead of patching the earlier report from memory.

- Report a conflicting source as a conflict to resolve, instead of choosing the value that looks most likely.
